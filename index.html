See it work

A synthetic case file, start to finish, with the instruction "anything that identifies the patient, but not the staff".

  1. Review

    Each proposal is numbered, coloured by the layer that found it, and has a reason.

  2. Burn

  3. Verify

    The output is read again; anything that couldn't be checked is listed.

A black box isn't a redaction

Removed, not covered

A box drawn over a name leaves the name in the file. Excisa removes the text, glyphs and image pixels underneath, and copies in form fields, bookmarks and metadata.

Found for you

Names in tables, numbers split across lines, form fields, scanned pages. Every proposal has a reason, so the reviewer checks instead of hunting.

Checked afterwards

Excisa reads the output again (by OCR on scans) and reports verified, failed or unverified, and why. It never claims more than it checked.

How it finds it

Three layers, cheapest and most certain first. Each job chooses which ones run.

Rules

E-mail, phone and card numbers, postal addresses, ID numbers (SSN, NI, IBAN, labelled passport and record numbers) and dates of birth. Deterministic and explainable.

Names

A local model finds people's names, then each name is searched for on every page and in every form field, so repeats aren't missed.

Your instruction

Say what to remove in plain language. A language model you run proposes passages, each with a reason. It never edits the document, and a passage counts only where it really occurs on the page.

Measured, not promised

On 27 synthetic documents (36 pages, 913 labelled items, including scans, tables, forms and rosters), with no manual review:

96%removed, with rules, names and the language model
100%of e-mail, phone, card, address, ID and date-of-birth labels
92%of names, counting every written form
0removed passages left in the output text

"Removed" counts what was gone from the output with every proposal accepted as is; a reviewer adds what's missed. Language model: qwen2.5:14b on one consumer GPU, about 23 s a page. Rules and names alone: about 60 ms a page, 78% removed.

Your documents stay with you

Self-hosted

One Docker image, with a review page and a REST API, on your own servers or cloud account. No telemetry. Job files are deleted when you're done or when they expire.

Bring your own model

The language model runs where you decide: on your own GPU today (Ollama), or an OpenAI-compatible endpoint in your own cloud on request. We test models on the same evaluation set and can tell you how yours compares.

Built on icepdf

Burning and verifying are done by icepdf, an open-source (Apache 2.0) Java PDF library from the same developer, so that part is open to inspection.
